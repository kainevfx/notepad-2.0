# Agent-suggested improvements

Not in the brief. Cheap to add once the core is built; ranked by value for the effort.

1. **Command palette (Ctrl+Shift+P).** Every action, every open note and every group, fuzzy searched. Makes a deep group tree fast to use.
2. **Search across all notes** (Ctrl+Shift+F) including closed quick notes in the store.
3. **Group = folder link.** Point a group at a folder (e.g. a project's `docs/`) and it lists the `.md`/`.txt` files live. Good for Kaine's Claudette plan folders.
4. **Quick Note to group routing.** A `#tag` on the first line files the quick note straight into the matching group.
5. **Copy as rich text / HTML** from Markdown preview, for pasting into emails and Google Docs.
6. **Export to PDF** from preview with the chosen paper background.
7. **Diff against saved** (the "Compare" button in the external-change bar also works on demand).
8. **Typewriter / focus mode** for writing: current line centred, others dimmed.
9. **Per-group colour on the taskbar thumbnail**, so a pinned workspace is recognisable.
10. **Portable mode** (settings next to the exe) for a USB stick on tour laptops.
